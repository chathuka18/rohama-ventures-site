# ROHAMA Ventures Website

Multi-page React + Tailwind CSS website for ROHAMA Ventures (Pvt) Ltd.

## Stack
- React 18
- Tailwind CSS 3
- Vite
- React Router
- Framer Motion
- Three.js + React Three Fiber
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Updates in this version
