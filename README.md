# ROHAMA Ventures Website

Updated React + Tailwind CSS multi-page website for **ROHAMA Ventures (Pvt) Ltd**.

## Included updates

- Actual uploaded ROHAMA logo integrated into navbar and footer
- Homepage hero redesigned with a real Colombo skyline visual
- Animated hero image treatment with floating info cards
- Content-related images added across Home, About, Services, and Service Detail pages
- Floating WhatsApp button linked to direct chat
- Multi-page routing with services, FAQ, clients, insights, and contact pages
- Vercel configuration included for SPA routing

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL, typically:

```bash
http://localhost:5173
```

## Deploy

You can deploy directly to Vercel after pushing the project to GitHub.
